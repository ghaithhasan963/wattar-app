# M10.1 — عقد أصول الهدايا ثلاثية الأبعاد (Pre-rendered)

## الهدف
كل هدية في واتار تعرض مشهد احتفال سينمائي ~5 ثوانٍ. المسار المعتمد: **أصول 3D مُصيّرة مسبقًا** (فيديو) مع fallback إجرائي موجود في `GiftScene` عند غياب الأصل.

## صيغة الأصل
- **الحاوية**: MP4 (H.264) أو WebM (VP9/alpha إن توفر). الأفضل توافقًا: MP4؛ للشفافية استخدم WebM مع alpha أو HEVC+alpha حيث مدعوم، وإلا فيديو بخلفية داكنة متوافقة مع المشهد.
- **المدة**: 4.5–5.5 ثانية (الهدف 5s).
- **الأبعاد**: 720x1280 (9:16) أو 1080x1920، safe area للمحتوى في الوسط.
- **الخلفية**: شفافة إن أمكن؛ بديل: خلفية داكنة `#07050C`/متدرجة تتماشى مع غرفة واتار.
- **الحجم**: يفضّل < 3MB للهدايا العادية، < 6MB للنادرة/الأسطورية.
- **الصوت**: اختياري؛ الافتراضي صامت (التطبيق يتحكم بالصوت لاحقًا). إن وُجد، يكون قصيرًا وغير مزعج.
- **Loop**: غير مطلوب؛ يُشغّل مرة واحدة.

## الربط في قاعدة البيانات
- الحقل: `public.gifts.animation_url` (text, nullable).
- القيمة: URL عام/CDN للأصل (Supabase Storage public bucket أو CDN خارجي).
- عند وجود `animation_url` قابل للتشغيل (mp4/webm/mov/m4v): `GiftScene` يشغّل الأصل.
- عند غياب/فشل الأصل: fallback إجرائي حسب الفئة السعرية.

## الفئات السعرية (giftTiers.ts)
| الفئة | النطاق (Coin) | الشدة | ملاحظات بصرية |
|---|---:|---|---|
| common | < 500 | خفيفة | توهج بسيط، جسيمات قليلة |
| special | 500–1999 | متوسطة | تأثير أوضح، حركة أكبر |
| rare | 2000–4999 | عالية | طبقات ضوء/جسيمات |
| epic | 5000–9999 | قوية | مشهد مميز، اهتزاز/توهج |
| legendary | 10000+ | قصوى | مشهد سينمائي كامل، تأثيرات متعددة |

## سلوك المشهد في التطبيق
1. يبدأ المشهد فور استلام حدث الهدية (محلي/Realtime).
2. يعرض الأصل 3D أو fallback ~5s.
3. عند النهاية: انكماش/انتقال إلى مقعد المستلم (`recipientId` -> seat target).
4. بعد الوصول: إدراج حدث الهدية في الشات/التكرت.

## تسمية مقترحة للأصول
`gifts/3d/{gift_slug}_v{n}.{ext}`  
مثال: `gifts/3d/rose_v1.mp4`, `gifts/3d/ship_v1.webm`

## قائمة التحقق لكل هدية
- [ ] `animation_url` معبأ.
- [ ] المدة ~5s.
- [ ] يعمل على Android/iOS.
- [ ] الحجم ضمن الحد.
- [ ] لا يحتوي نصًا حساسًا/علامة مائية خارجية.
- [ ] الفئة السعرية تطابق شدة المشهد.
