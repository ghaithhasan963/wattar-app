## 2) مؤكد منك (المدير) — تحديث 2026-11-14

- جميع أسرار GitHub وSupabase موجودة وبقيمها الصحيحة.
- تسجيل الدخول بGoogle يعمل.
- الصوت في الغرف يعمل على جهازك عبر LiveKit.
- **SMTP غير مضبوط عملياً:** التسجيل عبر Google يعمل، لكن **لا تحقق بريدي** ولا رسائل بريد تُرسل.
- **الفرع الأساسي:** النشر يتم على الفرع الأساسي. الفرع الافتراضي على GitHub هو **`master`** (مؤكد بالأمر `git symbolic-ref refs/remotes/origin/HEAD`)، وأنت تسمّيه «main».
- **مفتاح الإصدار:** يُولَّد فقط عند طلبك نشرة معاينة/تجربة، لا الآن.
- **لوحة الإدارة:** مستضافة وتعمل على **Vercel**: `https://wattar-admin.vercel.app/`.

هذه معلومات تشغيلية مهمة، لكنها **ليست إثباتاً مكتوباً** بعد. ستتحول إلى «مؤكد باختبار» في M1 وM6.

## 5) حدود الطبقات المجانية — ما يجب قياسه قبل التصميم

لا أعتمد على كلمة «مجاني» بلا رقم. في M0 نسجّل **الحد والاستهلاك الحالي** لكل بند:

| الخدمة | ما يُسجّل |
|---|---|
| Supabase | خطة المشروع · حجم القاعدة · حجم Storage · MAU · استدعاءات Edge · اتصالات Realtime المتزامنة · حد الإيقاف بسبب الخمول |
| LiveKit | الخطة · الدقائق الشهرية المتاحة · الدقائق المستهلكة · حد المشاركين |
| GitHub Actions | الدقائق المجانية شهرياً · المستهلك · مدة بناء APK الواحد |
| FCM | مجاني بلا حد تشغيلي مؤثر (يُتحقق) |
| استضافة لوحة الإدارة | المنصة الحالية · حدود النطاق الترددي |
| CDN/التخزين البديل | يُقاس فقط إذا قررنا R2 في M9.5 — وليس الآن |

**قاعدة:** أي رقم قريب من الحد يعني توقفاً مفاجئاً للمنصة. لذلك حدود التخزين وضغط الصور تُصمم من M2، لا في M10.
