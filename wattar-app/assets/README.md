# Wattar App — الأصول المطلوبة

ضع الملفات التالية في هذا المجلد:

## الأيقونات الأساسية
- `icon.png` — أيقونة التطبيق (1024x1024)
- `adaptive-icon.png` — أيقونة Android التكيفية (1024x1024)
- `favicon.png` — أيقونة المتصفح (48x48)
- `splash.png` — شاشة البداية (1242x2436)

## إطارات وأيقونات إضافية (للميزات المستقبلية)
- `frames/` — إطارات الصور الشخصية (PNG، شفافة)
- `gifts/` — أيقونات الهدايا (JSON Lottie أو PNG)
- `sounds/` — مؤثرات صوتية (mp3، قصيرة)
